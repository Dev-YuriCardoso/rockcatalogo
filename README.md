# RockCatalogo

Crie uma aplicação web moderna em React com Tailwind CSS e shadcn/ui. O site é um catálogo focado em moda e lifestyle Rock. A estética deve ser dark, puxando para tons góticos e estúdio profissional: fundo quase preto (ex: zinc-950), tipografia limpa, bordas sutis em cinza escuro e botões de destaque em cores contrastantes (como um vermelho escuro ou um branco puro).

Requisitos estruturais:

Uma Navbar fixa com logo em texto estilizado e links para as subcategorias: 'Acessórios', 'Camisas', 'Calças', 'Mochilas' e 'Looks Completos'.

Uma seção Hero dramática no topo da página inicial, com um título forte sobre encontrar o melhor do estilo rock e um botão de 'Ver Catálogo'.

Um rodapé (Footer) simples com links e aviso de que os produtos redirecionam para loja parceira. Crie apenas a casca principal com navegação funcional usando React Router."

Prompt 2: Componentes de Produto e Grid

"Agora, crie a página principal de listagem de produtos (Home/Catálogo) e o componente de Card de Produto.

Detalhes do Card de Produto:

Deve ter um layout limpo no estilo dark.

Mostrar imagem do produto, título, subcategoria e o preço estimado.

O botão principal do card deve dizer 'Comprar na Shopee' e ter um ícone de link externo. Ao clicar, ele deve abrir uma nova aba (target='_blank').

Detalhes da Página:

Um sistema de filtros lateral ou superior para alternar entre as categorias (Acessórios, Camisas, Calças, Mochilas).

Uma seção especial chamada 'Looks Completos', que exibe cards maiores contendo uma combinação de peças sugerida.

Preencha a tela com dados mockados (falsos) de produtos com temática rock/gótica para que eu possa ver o layout completo em funcionamento."
